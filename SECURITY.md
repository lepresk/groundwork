# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting ("Security" tab, "Report a vulnerability") with a description, reproduction steps, and the affected version or commit.

You will get an acknowledgment within 5 business days. Fixes for confirmed issues are released as soon as possible and credited unless you prefer otherwise.

## Scope

This is a starter template. Vulnerabilities in the template code (authentication, sessions, input validation, BFF cookie handling, Docker images, CI) are in scope. Projects built from it are maintained by their owners.
