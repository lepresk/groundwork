# 0006. Drizzle ORM with generated SQL migrations

- **Status:** accepted

## Context

The team needs type-safe queries close to SQL, reviewable migrations, and no runtime code generation step.

## Decision

Drizzle ORM with the node-postgres driver, schema in `packages/db/src/schema`, snake_case column mapping, and SQL migrations generated by drizzle-kit (`pnpm db:generate`) and applied by a standalone runner (`dist/migrate.js`).

## Consequences

- Migrations are plain SQL files, reviewed like code and never edited once applied.
- Queries stay explicit; repositories are the only layer that uses Drizzle.
- The migration runner works in production images without dev dependencies.
